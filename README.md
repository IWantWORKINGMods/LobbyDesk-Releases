# LobbyDesk downloads

Windows app by **IWANTMOREMODS**.

[Download LobbyDesk.exe](https://github.com/IWantWORKINGMods/LobbyDesk-Releases/releases/latest/download/LobbyDesk.exe) · [Release notes](https://github.com/IWantWORKINGMods/LobbyDesk-Releases/releases) · [Support](https://github.com/IWantWORKINGMods/LobbyDesk-Releases/issues)

This repository contains public downloads and support information. Application source and build workflows are maintained separately.

1. Download **LobbyDesk.exe** from a published release below. Windows 10/11 x64 is required; no separate Node installation is needed.
2. Place it in a writable folder, open it, and enter your license key on the activation screen. Version 1.1.3 continues to use the **test licensing service**; it does not enable live purchases.
3. Use **Check for updates** for later versions. Upgrades keep your saved profiles and protected Epic account links.

If an older copy cannot check for updates, close it and replace its EXE with the current download once. Keep your `%LOCALAPPDATA%\LobbyDesk` data folder.

Choose **LobbyDesk.exe** or **LobbyDesk-vVERSION.zip** under release assets. The app ZIP includes the user guide and required license notices. GitHub's automatic **Source code** archives contain only this repository's documentation, not the application.

The executable is currently unsigned. The updater verifies its download size, SHA-256 and embedded version. This does not make the binary impossible to copy or reverse engineer; activation is required by the app.

LobbyDesk is independent software, not affiliated with Epic Games. It is a lobby companion, not an in-match AFK player, and does not guarantee AI-only opponents.

When reporting a problem, include the app version and redacted error text. Never post your license key, Epic login codes, account files, or payment details.
